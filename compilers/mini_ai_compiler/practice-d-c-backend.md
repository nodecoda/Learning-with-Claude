## 背景

前四章分别讲了循环、matmul tiling、向量化和 DLL 运行时。真实的后端不是四段独立的代码，而是一条链：

```text
Graph
  -> 校验（shape/dtype/SSA）
  -> 内存规划（offset、arena_bytes）
  -> C 源码（常量、指针绑定、循环、输出拷贝）
  -> cl /LD /O2 /fp:fast
  -> DLL
  -> ctypes（argtypes/restype）
  -> 输出 ndarray
  -> 与解释器/PyTorch 差分
```

任何一环错位，最后都会表现成“数值不对”或“程序崩溃”。这个练习要求你把整条链自己接一遍，而不是只写一个孤立的 `for` 循环。

## 任务规格

### 必须实现

你的后端至少要支持：

- `add`、`sub`、`mul`、`div`、`relu`、`exp`、`add_relu`；
- `matmul`、`matmul_bias`、`matmul_bias_relu`；
- `sum`，支持 `axis`（含负数）和 `keepdims`；
- 任意 rank 的 elementwise 和 broadcast（在 `broadcast_strides` 能表达的范围内）；
- 输出拷贝到调用者提供的 `float*`；
- 失败时返回非零错误码。

不要求支持 softmax、动态 shape、非 float32、非 row-major 布局。

### ABI 契约

生成的 DLL 必须导出：

```c
MINI_EXPORT int mini_forward(
    const float* x0, ..., const float* xN,
    float* out0, ..., float* outM
);
```

约定：

- 输入在前，输出在后，顺序与 `graph.inputs`、`graph.outputs` 一致。
- 所有指针指向连续 float32 数组，长度由建图时的 shape 决定。
- 返回 `0` 表示成功，非零表示失败。
- 输出由调用者分配；DLL 不返回内部 arena 指针。

### 约束

- 生成的 C 不依赖 NumPy、PyTorch 或 BLAS。
- 每个 value 只定义一次；中间结果写到 arena。
- arena 按 64 字节对齐，offset 来自 `plan_memory`。
- 不允许把输入直接当输出写，除非你明确验证过没有其他读者。
- 测试必须包含至少一个失败路径。

## 卡点提示

1. **指针绑定顺序。** 先把 `graph.inputs` 绑定到 `x0..xN`，再把 `graph.outputs` 绑定到 `out0..outM`，最后才是常量和 arena。顺序错了，`ctypes` 不会报错，只会把参数传到错误的位置。
2. **常量的 shape。** `add_const` 接受标量、1-D、2-D 数组；生成 C 时按 `reshape(-1)` 写成一维数组，但索引仍要按原始 shape 计算广播。
3. **buffer 复用。** 不要自己随手把两个 value 指到同一个 offset。用 `plan_memory` 的 live interval，或者先全部独立分配，再逐步引入复用。
4. **归约清零。** `sum` 的输出必须在使用前清零；arena 不保证初始为 0。
5. **`ctypes` 的生命周期。** `argtypes` 必须在调用前设置；DLL 对象和 ndarray 必须活到调用结束；输出数组必须 C-contiguous、float32。

## 实现步骤

### 第 1 步：C 文件骨架与指针绑定

先生成一个能编译的空函数：

```c
/* Generated by practice C backend. */
#include <stddef.h>
#include <math.h>
#if defined(_MSC_VER)
#include <malloc.h>
#endif

#if defined(_MSC_VER)
#define MINI_EXPORT __declspec(dllexport)
#else
#define MINI_EXPORT
#endif

MINI_EXPORT int mini_forward(const float* x0, float* out0) {
    const size_t arena_bytes = 64;
#if defined(_MSC_VER)
    float* arena = (float*)_aligned_malloc(arena_bytes, 64);
#else
    float* arena = (float*)aligned_alloc(64, arena_bytes);
#endif
    if (!arena) return 1;

    /* bind values here */

#if defined(_MSC_VER)
    _aligned_free(arena);
#else
    free(arena);
#endif
    return 0;
}
```

配套实现的 `emit` 用同样的结构，但参数列表由 `graph.inputs` 和 `graph.outputs` 动态拼接：

```python
sig_inputs = [f"const float* x{i}" for i in range(len(self.graph.inputs))]
sig_outputs = [f"float* out{i}" for i in range(len(self.graph.outputs))]
lines.append(f"MINI_EXPORT int {self.function_name}({', '.join(sig_inputs + sig_outputs)}) {{")
```

value 到 C 变量的命名规则是：

```python
self.value_name = {id(v): f"v_{v.id}_{_ident(v.name)}" for v in graph.values}
```

`_ident` 把非字母数字下划线替换成 `_`，避免 value 名里的点号、斜杠破坏 C 标识符。常量单独用 `C_{id}`，因为常量要定义成文件级 `static const float` 数组。

### 第 2 步：elementwise 与广播索引

实现两个纯函数，先把 shape/stride 变成字符串：

```python
def linear_index(shape, strides, vars_):
    terms = []
    for d, s, var in zip(shape, strides, vars_):
        if s == 0:
            continue
        terms.append(var if s == 1 else f"({var})*{s}")
    return " + ".join(terms) if terms else "0"


def broadcast_index(shape, out_shape, vars_):
    return linear_index(out_shape, broadcast_strides(shape, out_shape), vars_)
```

然后按输出 rank 生成循环：

```python
out_shape = op.output.type.shape
vars_ = [f"i{op.id}_{d}" for d in range(len(out_shape))]
indent = "    "
for d, n in enumerate(out_shape):
    lines.append(f"{indent}for (int {vars_[d]} = 0; {vars_[d]} < {n}; ++{vars_[d]}) {{")
    indent += "    "
out_idx = linear_index(out_shape, TensorType(out_shape).strides, vars_)
```

循环体里，每个输入的下标用 `broadcast_index(v.type.shape, out_shape, vars_)`。这一步完成后，`(2,3)+(3,)`、`(4,1)+(1,3)` 和同 shape 的逐元素运算都能工作。

### 第 3 步：matmul 与归约

matmul 的三重循环：

```python
m, k = a.type.shape
k2, n = b.type.shape
i, j, kk = f"i{op.id}", f"j{op.id}", f"k{op.id}"
lines.append(f"    for (int {i} = 0; {i} < {m}; ++{i}) {{")
lines.append(f"        for (int {j} = 0; {j} < {n}; ++{j}) {{")
lines.append("            float acc = 0.0f;")
lines.append(f"            for (int {kk} = 0; {kk} < {k}; ++{kk}) {{")
lines.append(f"                acc += A[({i})*{k} + ({kk})] * B[({kk})*{n} + ({j})];")
lines.append("            }")
lines.append(f"            C[({i})*{n} + ({j})] = acc;")
lines.append("        }")
lines.append("    }")
```

实际实现把 `A`、`B`、`C` 换成 `self.ptr(a)`、`self.ptr(b)`、`self.ptr(out)`，并在 `acc` 写回前插入 bias 和 relu。`matmul_bias_relu` 的 epilogue 顺序必须是 `+bias` 再 `fmaxf`，不能反过来。

归约：

```python
lines.append(f"    for (int z = 0; z < {max(1, out.type.numel)}; ++z) {self.ptr(out)}[z] = 0.0f;")
if axis is None:
    lines.append(f"    for (int z = 0; z < {max(1, x.type.numel)}; ++z) {self.ptr(out)}[0] += {self.ptr(x)}[z];")
    return
if axis < 0:
    axis += rank
```

然后遍历输入 shape，按 `keepdims` 决定输出下标是保留 `0` 还是删除该维。完整代码见 Ch 17 的 `_emit_sum`。

### 第 4 步：内存规划与 arena

调用配套的 `plan_memory(graph)`，它返回 `MemoryPlan`：

```python
from mini_ai.memory import plan_memory

plan = plan_memory(graph)
arena_bytes = max(64, plan.arena_bytes)
```

对每个 value：

- `input`：`const float* v = x{i};`
- `constant`：`const float* v = C_{id};`
- 有 allocation 的 temp：`float* v = (float*)((char*)arena + offset);`

不要给输入或常量分配 arena 空间。输出 value 的 allocation 仍然在 arena 里，最后统一拷贝到 `out{i}`。

检查三件事：

1. 每个 offset 是 64 的倍数。
2. `offset + size <= arena_bytes`。
3. 同时活跃的两个 buffer 不重叠。

`plan.validate()` 已经做了这些检查；你自己的实现至少要复现其中前两项。

### 第 5 步：编译 DLL 与 `ctypes` 调用

用 `compile_c` 的批处理模式：

```python

code_path.write_text(code, encoding="utf-8")
bat = build / "build.bat"
bat.write_text(

    "exit /b %errorlevel%\n",
    encoding="utf-8",

```

调用侧：

```python
lib = ctypes.CDLL(str(dll_path))
fn = getattr(lib, "mini_forward")
ptr = ctypes.POINTER(ctypes.c_float)
fn.argtypes = [ptr] * (n_inputs + n_outputs)
fn.restype = ctypes.c_int

args = [np.ascontiguousarray(a, dtype=np.float32).ctypes.data_as(ptr) for a in inputs]
args += [np.zeros(shape, dtype=np.float32).ctypes.data_as(ptr) for shape in output_shapes]
rc = fn(*args)
```

`argtypes` 必须在调用前设置；`lib` 和所有 ndarray 必须在调用期间保持存活。返回码不是 0 时抛异常，不要继续读输出。

### 生成器入口

```python
class CCodegen:
    def __init__(self, graph, plan=None, *, function_name="mini_forward"):
        self.graph = graph
        self.plan = plan or plan_memory(graph)
        self.function_name = function_name
        self.input_index = {id(v): i for i, v in enumerate(graph.inputs)}
        self.output_index = {id(v): i for i, v in enumerate(graph.outputs)}
        self.value_name = {id(v): f"v_{v.id}_{_ident(v.name)}" for v in graph.values}
        self.const_name = {id(v): f"C_{v.id}" for v in graph.values if v.kind == "constant"}
```

构造函数做三件事：保存图、规划内存、建立 value 到 C 名字的映射。`input_index` 和 `output_index` 用来生成参数名；`value_name` 用来生成局部指针名。

### 生成函数骨架

```python
def emit(self):
    self.graph.validate()
    lines = ["/* Generated by mini_ai.codegen_c. */", "#include <stddef.h>", "#include <math.h>", "#include <malloc.h>"]
    # ... 常量数组、MINI_EXPORT 宏 ...
    sig_inputs = [f"const float* x{i}" for i in range(len(self.graph.inputs))]
    sig_outputs = [f"float* out{i}" for i in range(len(self.graph.outputs))]
    lines.append(f"MINI_EXPORT int {self.function_name}({', '.join(sig_inputs + sig_outputs)}) {{")
    arena = max(64, self.plan.arena_bytes)
    lines.append(f"    const size_t arena_bytes = {arena};")
    lines.append("    float* arena = (float*)_aligned_malloc(arena_bytes, 64);")
    lines.append("    if (!arena) return 1;")
    for v in self.graph.values:
        if v.kind == "input":
            lines.append(f"    const float* {self.ptr(v)} = x{self.input_index[id(v)]};")
        elif v.kind == "constant":
            lines.append(f"    const float* {self.ptr(v)} = {self.const_name[id(v)]};")
        elif id(v) in {id(a.value) for a in self.plan.allocations.values()}:
            off = self.plan.offset_of(v)
            lines.append(f"    float* {self.ptr(v)} = (float*)((char*)arena + {off});")
    for op in self.graph.ops:
        self._emit_op(op, lines)
    for i, v in enumerate(self.graph.outputs):
        n = max(1, v.type.numel)
        lines.append(f"    for (int i = 0; i < {n}; ++i) out{i}[i] = {self.ptr(v)}[i];")
    lines.append("    _aligned_free(arena);")
    lines.append("    return 0;")
    lines.append("}")
    return "\n".join(lines) + "\n"
```

逐段解释：

- `validate()` 在建图阶段挡住 SSA、shape、输出缺失等错误；生成器不重复做完整校验。
- 先声明常量，再声明函数；常量是文件级 `static const`，不占 arena。
- 输入指针直接指向 `x{i}`，不复制。调用者必须保证输入在调用期间有效。
- arena 内的 value 用 `(char*)arena + offset` 做字节偏移，再转回 `float*`；offset 由规划器保证 64 对齐。
- 所有 op 生成完后，统一拷贝输出。这样 `out{i}` 不需要参与中间计算，也不会和 arena 的复用规则冲突。
- 释放 arena 后返回 0；分配失败返回 1。

### elementwise 与广播

```python
def _emit_elementwise(self, op, lines):
    out_shape = op.output.type.shape
    rank = len(out_shape)
    vars_ = [f"i{op.id}_{d}" for d in range(rank)]
    indent = "    "
    if rank == 0:
        self._emit_expr(op, lines, indent, [], "0")
        return
    for d, n in enumerate(out_shape):
        lines.append(f"{indent}for (int {vars_[d]} = 0; {vars_[d]} < {n}; ++{vars_[d]}) {{")
        indent += "    "
    out_idx = _linear_index(out_shape, TensorType(out_shape).strides, vars_)
    self._emit_expr(op, lines, indent, vars_, out_idx)
    for _ in out_shape:
        indent = indent[:-4]
        lines.append(f"{indent}}}")
```

这里的关键是 `out_shape` 而不是输入 shape。`_emit_expr` 再对每个输入调用 `_broadcast_index`，把输入维度对齐到输出。rank 0 单独处理，否则 `for` 循环一层都不会生成，赋值语句也不会发出。

### matmul 与 epilogue

```python
def _emit_matmul(self, op, lines):
    a, b = op.inputs[0], op.inputs[1]
    m, k = a.type.shape
    k2, n = b.type.shape
    if k != k2:
        raise IRError(f"matmul shape mismatch: {a.type.shape} @ {b.type.shape}")
    out = op.output
    bias = op.inputs[2] if len(op.inputs) == 3 else None
    i, j, kk = f"i{op.id}", f"j{op.id}", f"k{op.id}"
    lines.append(f"    for (int {i} = 0; {i} < {m}; ++{i}) {{")
    lines.append(f"        for (int {j} = 0; {j} < {n}; ++{j}) {{")
    lines.append("            float acc = 0.0f;")
    lines.append(f"            for (int {kk} = 0; {kk} < {k}; ++{kk}) {{")
    lines.append(f"                acc += {self.ptr(a)}[({i})*{k} + ({kk})] * {self.ptr(b)}[({kk})*{n} + ({j})];")
    lines.append("            }")
    if bias is not None:
        bias_idx = _broadcast_index(bias.type.shape, (m, n), [i, j])
        lines.append(f"            acc += {self.ptr(bias)}[{bias_idx}];")
    if op.kind == "matmul_bias_relu":
        lines.append("            acc = fmaxf(acc, 0.0f);")
    lines.append(f"            {self.ptr(out)}[({i})*{n} + ({j})] = acc;")
    lines.append("        }")
    lines.append("    }")
```

`acc` 放在最内层循环外，保证每个输出元素只初始化一次。bias 的下标用输出 shape `(m,n)` 做广播，所以 `(n,)`、`(1,n)`、`()` 都能工作。relu 只在 `matmul_bias_relu` 里出现，且必须在 bias 之后。

### 归约

```python
def _emit_sum(self, op, lines):
    x, out = op.inputs[0], op.output
    axis = op.attrs.get("axis", None)
    keepdims = bool(op.attrs.get("keepdims", False))
    shape = x.type.shape
    vars_ = [f"i{op.id}_{d}" for d in range(len(shape))]
    lines.append(f"    for (int z = 0; z < {max(1, out.type.numel)}; ++z) {self.ptr(out)}[z] = 0.0f;")
    if axis is None:
        lines.append(f"    for (int z = 0; z < {max(1, x.type.numel)}; ++z) {self.ptr(out)}[0] += {self.ptr(x)}[z];")
        return
    if axis < 0:
        axis += len(shape)
    indent = "    "
    for d, dim in enumerate(shape):
        lines.append(f"{indent}for (int {vars_[d]} = 0; {vars_[d]} < {dim}; ++{vars_[d]}) {{")
        indent += "    "
    in_idx = _linear_index(shape, TensorType(shape).strides, vars_)
    out_vars = [v if d != axis else "0" for d, v in enumerate(vars_)] if keepdims else [v for d, v in enumerate(vars_) if d != axis]
    out_idx = _linear_index(out.type.shape, TensorType(out.type.shape).strides, out_vars)
    lines.append(f"{indent}{self.ptr(out)}[{out_idx}] += {self.ptr(x)}[{in_idx}];")
    for _ in shape:
        indent = indent[:-4]
        lines.append(f"{indent}}}")
```

`axis=None` 是快路径；否则遍历输入全 shape，输出下标按 `keepdims` 生成。`out_vars` 的长度必须等于输出 rank，否则 `_linear_index` 的 `zip` 会静默截断，生成错误下标。这是实现时需要特别检查的地方。

为便于阅读，这段把返回值简化为 `(code_path, dll_path)`；配套实现返回 `CCompileResult`，其中还带 `build_log`。注意 `cwd=build`：`build.bat` 里的相对文件名是相对构建目录的。如果你在仓库根目录运行 `cl`，生成的 `.obj`、`.dll` 会散落在根目录，测试之间互相覆盖。

### 运行时包装

```python
def load_c_function(dll_path, n_inputs, n_outputs, *, symbol="mini_forward"):
    lib = ctypes.CDLL(str(Path(dll_path)))
    fn = getattr(lib, symbol)
    ptr = ctypes.POINTER(ctypes.c_float)
    fn.argtypes = [ptr] * (n_inputs + n_outputs)
    fn.restype = ctypes.c_int

    def run(inputs, output_shapes):
        if len(inputs) != n_inputs:
            raise ValueError(f"expected {n_inputs} inputs, got {len(inputs)}")
        ins = [np.ascontiguousarray(a, dtype=np.float32) for a in inputs]
        outs = [np.zeros(s, dtype=np.float32) for s in output_shapes]
        args = [a.ctypes.data_as(ptr) for a in ins]
        args += [a.ctypes.data_as(ptr) for a in outs]
        rc = fn(*args)
        if rc != 0:
            raise RuntimeError(f"{symbol} returned error code {rc}")
        return outs

    run.lib = lib
    return run
```

`run.lib = lib` 让闭包显式持有 DLL 对象。当前 CPython 的 ctypes 函数对象也会通过 `_objects` 持有库，但把引用写在包装层更清楚，不依赖实现细节。`ins` 和 `outs` 是局部变量，在 `fn(*args)` 返回前一直存活；返回后 `outs` 被返回，调用者持有引用。

## 延伸挑战

1. **多输出图。** 让 `emit` 支持多个 `graph.outputs`，每个输出一个 `out{i}`，并写多输出差分测试。
2. **错误码分层。** 把 arena 分配失败、空指针、未实现 op 分别映射到不同非零码，并在 Python 侧抛不同异常。
3. **tiled matmul。** 把 Ch 18 的 tile 逻辑接进 `_emit_matmul`，用 `autotune_matmul.py` 的 8 组配置测同一张图。
4. **动态 shape。** 把维度从字面量改成函数参数，增加 shape 检查；比较代码大小和优化效果。
5. **LLVM 对照。** 用 Ch 21–22 的 `LLVMJIT` 跑同一批图，比较 C 和 LLVM 的 maxerr、median 和生成代码行数。
6. **随机图差分。** 随机生成 100 张由支持算子组成的图，逐张比较解释器和 DLL；记录第一个失败的图并最小化。
