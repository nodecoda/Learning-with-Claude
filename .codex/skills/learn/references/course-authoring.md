## Final Project 要點

- 整合全課至少 70% 核心概念，不是最後幾章的延伸
- 500–700 行，有明確的驗收標準與可執行步驟
- 提供分階段里程碑，讀者不會一次被整份規格淹沒
- 能跑就跑；環境不允許時標注需要什麼環境才能驗證

## course-scope memory

檔名 `user_<topic>_learning.md`（repo 根目錄），frontmatter 的 `name:` 用 `<topic>-course-scope`：

```markdown
---
name: <topic>-course-scope
description: <一句話：主題、規模（N ch + M 練習 + 1 final）、深度取向、對口目標（若有）>
metadata:
  type: project
---

`<category>/<topic>/` <這門課的定位：求什麼、不求什麼、對口什麼場景>。

**Why:** <為什麼這樣切範圍與深度——使用者的目標、背景、特殊約束。把 Step 1 對齊到的東西寫進來。>

**How to apply:**
- <檔案結構：N 檔 = README + Ch 0–X + 練習 + final>
- <分 Part 的骨架一行摘要>
- <刻意涵蓋 / 刻意不涵蓋 的邊界>
- <這門課特有的學習信條或核心場景>
```

完成後補一行 `✅ 全部完成 (YYYY-MM-DD)：<章數、行數、索引同步狀態>`，並在 `MEMORY.md` 登錄指標行。既有檔案（例如 `user_mlir_core_learning.md`）就是這個格式的實例。
